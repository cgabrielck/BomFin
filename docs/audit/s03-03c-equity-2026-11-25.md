## Rulings and limitations

- Official [subscription guidance](https://openapi.futunn.com/futu-api-doc/en/qa/quote.html) requires a minimum minute; immediate unsubscribe would not reliably free quota. Extra elapsed time is deliberate cleanup cost. Parent timeout 110s covers startup/calls/hold/close; a killed worker may leave server quota until the documented minimum expires, so metadata recheck remains mandatory after timeout.
- [Quote](https://openapi.futunn.com/futu-api-doc/en/quote/get-stock-quote.html) data_date/data_time and [day-bar](https://openapi.futunn.com/futu-api-doc/en/quote/get-kl.html) time_key are retained with documented America/New_York source timezone. D1 midnight timestamp is a bar label, not an intraday execution time; no freshness, exact bar-end or finalized status is invented.
- SDK float values are converted with Decimal(str(value)) at this provider boundary; this preserves the SDK's observed decimal string, not original wire precision. Nonfinite/missing values stay null or fail the diagnostic, never become zero.
- This quote endpoint reports last price; bid/ask depths, live push timestamps, volume deduplication, OHLC integrity enforcement, full native QuoteSnapshot/Bar production and canonical symbol registry remain later integration work.
- Returned prices are observations, not investment recommendations. A successful read at a closed-market time cannot establish feed realtime latency or PRE/POST eligibility. Options/history permissions remain unknown.
