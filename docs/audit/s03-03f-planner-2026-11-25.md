## 交付行為

- `InstrumentCatalog` 以 source/symbol 精確映射 caller 提供的 canonical UUID，
  拒絕衝突、缺 underlying／非 equity underlying，以及股票冒用可識別期權碼。
  來源與返回物件均防禦性複製；不猜測 tick／lot／currency／option metadata。
- Futu US 期權碼與 underlying、expiry、right、strike 核對；Decimal 字串直接
  建構避免 ambient precision 改變比對。共用 ticker grammar 支援 `.`／`-`。
  非 US 的合法 metadata 可登錄，由本 US planner 逐項回 market_unsupported。
- 沿用既有 Demand、SubscriptionKey、FeedCapabilities、SubscriptionPlan，
  新增記憶體 config／Schedule，不改 wire schema。接受結果只是目標，不是已執行訂閱。
- 優先 holding > chart > strategy > watchlist > candidate；同級固定 UUID／key
  排序，非公平排程承諾。精確 key 去重；任一 owner 需求仍有效就保留共用 key。
  expires_at <= as_of 到期；可靠快照下可釋放最後需求已消失的本連線 key。
- 普通與期權鏈分池；期權同 underlying／expiry／channel／timeframe 共用成本。
  Budget 是排除外部 context 保留後、本 planner 全部目標可用容量，包含自身已有 key；
  不是只供新增的 remain。Scope／checked_at／TTL 皆明確輸入，沒有預設 runtime 風控值。
- channel 支援按 asset_class／session／channel／timeframe 明確宣告；股票 PRE
  不會推出期權 PRE，也不從 history_limits 或 latency unknown 推出 realtime 權益。
- 即使沒有有效需求，stale／future／permission error／未知受影響 pool 仍凍結。
  新 catalog 暫缺 current identity 也凍結，不視為離頁；blocked_reasons 說明原因。
- 返回 subscribe／unsubscribe 只針對 caller 宣告的本 context current logical keys；
  本單位只以 fake FeedAdapter 演示先釋放低優先、再新增高優先，不接真實 OpenD。

## 使用界線與下一步

- 本 catalog 是有限且 caller 已核對的 metadata 快照，不是完整市場匯入／持久化。
  支援 grammar 不等於證明某個合成 ticker 真實存在、可交易或已獲行情授權。
- Demand.owner／priority 由上游授權；本 planner 不負責 auth。current 的擁有權
  亦是 caller 前提，不能把任意 provider／其他 context 的 key 混入。
- 計劃是 advisory；真實 provider apply、release ACK、最短持有期、其他連線保留、
  callback／cache／freshness 與故障恢復仍需 coordinator。freeze 不代表既有資料健康。
- 只對精確 timeframe 去重，不合併等價 timeframe 或衍生 bar；native topic 編碼及
  複用尚待 adapter。此 quota 模型不可套其他 provider 或不同計費規則。
- 本次沒有 OpenD／帳戶／券商／模型呼叫或實際交易，沒有變更行情權益證據。
- 下一單位 S03/03g：一股 quote 的 FeedAdapter／callback→有界 cache 切片，
  接上 typed MarketEvent，驗證 lifecycle、來源時間與初始／stale 狀態。

Futu quota 單位依 [官方規則](https://openapi.futunn.com/futu-api-doc/en/intro/authority.html)：
普通每標的每資料類型計額；期權同到期鏈的同資料類型共用獨立期權額度。
