## 交付及界線

- `create_market_app` 組裝既有 auth、POST snapshot、只讀 WebSocket 與可選 static dist。
  Exact HTTPS／Host／Origin、Secure／HttpOnly session、session-bound CSRF、到期／撤銷持續核對。
  可讀 `__Host-gabfin_csrf` cookie 支援重載；實際 auth token 仍只在 HttpOnly cookie。
- instrument scope、有限 key 集合、握手／body／frame 上限、client 容量、時間限制及清理失敗拒絕重用。
  每個新 browser stream 都先完整 snapshot；序號不連續不轉送壞 update。
- `MarketGateway.from_store` 每個內部連線建立 read_market service lease，關閉後撤銷，
  避免舊 token 到期阻斷新的配對。store／listener／source／keys 由可信主機設定；browser 不能指定。
  一個 S03 producer 繼續持有 SDK；瀏覽器只連內部 consumer，不另開 SDK。
- 新增資料模式／配對／登出 UI；server snapshot 與 frames 依 canonical schema 作 runtime validation，
  核對股票／channel／來源，decimal 維持字串，counter 限 lossless JS integer。
  heavy validator 僅在 server mode 動態載入。React 每 animation frame 合併更新、取消離頁請求。
- 切股隔離、完整 reset、有界重連三次；失效／登出清除報價，來源 age、品質、gap 與連線分開顯示。
  預設仍是 demo；研究／候選仍明示示例，帳戶保持未知。沒有假 K 線／成交量。
- 提供 factory／測試入口，未交付長駐 operator launcher、遠端 HTTPS、任意 symbol catalog 或部署。
  [應用啟動／依賴及用法](../../../apps/desk-web/README.md)。
