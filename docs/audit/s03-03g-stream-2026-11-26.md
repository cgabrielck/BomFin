## 交付行為

- `FutuQuoteAdapter` 實作 quote-only FeedAdapter：caller 提供有限 canonical catalog，
  只容許設定的一個 US equity quote key；同時 subscribe 共用 ready 結果。
  單次生命週期最多 90–120 秒，並非常駐行情服務或已整合的訂閱 coordinator。
- SDK 留在隔離 venv／子程序，只有行情 context。Callback thread 把完整觀察送進
  一個 thread-safe slot，父程序以私有 pipe 即時讀取；沒有行情 snapshot 輪詢。
  正常 stdout／stderr 在 SDK 匯入前丟棄；白名單 JSON 使用獨立繼承 descriptor。
- IPC 雙向檢查版本、欄位、大小及型別。主程序驗證價格字串／來源時間／股票，
  再轉成 `QuoteMarketEvent`；市場 `QuoteStream.apply` 只接 typed 事件，不認識 Futu wire。
- SDK slot、market latest、pending quote 各只留一筆；慢讀者合併，較舊來源時間及
  重複觀察不覆蓋較新資料，不靠收到重複推送刷新價格年齡。同時刻價變視為新觀察。
  僅保留最後一筆 dedup 身份，不是持久去重／全歷史重播。
- 來源 NY 時間轉 UTC；DST 不存在／重複時間及時鐘超前會拒絕，沒有猜測 fold。
  event/received/available 各自保留。沒有 BBO 就保持 None，session／權益為 unknown；
  quote quality 顯示 unknown/incomplete。年齡只相對 snapshot.as_of，並非讀取時的即時計時器。
- 取消前先檢查 stop；已嘗試訂閱（包括失敗可能部分配置）則至少等待 61 秒後
  只退訂本 context 的該股票 QUOTE，核對 own_used=0，再 close。預檢已有訂閱就拒絕接管。
  重複 close 可用；額外 events 讀者被拒而不會終止合法讀者。
- 自然到期、錯誤及取消都回收程序；hang 有外部 deadline、kill/wait，不能確認
  清理時保留 failure，不會把程序退出當成 quota 已釋放。終止結果失敗亦會傳給等待讀者。

## 限制及下一步

- Catalog tick/lot 在 live 示範中是明示診斷 fixture，未當作 security master 證明，
  也沒有供交易使用。FeedCapabilities 明確回報 live_manifest_unverified，不推出 realtime。
- 此為繼承的私有 SDK IPC，沒有新 listener。Task 5 的 authenticated loopback
  市場/API stream、常駐重連、補缺、Bar Builder、交易 freshness 政策及 UI tracing 尚未交付。
- Quote callback 不是 trade tick，不能用更新次數累加成交量；同時刻修訂及持續完整性
  仍受來源精度限制。clock skew／DST 拒絕數只是資料品質訊號，沒有執行訂單的權限。
- 下一單位 03h：新鮮度／heartbeat／bar 行為，先離線定義 stale、late、duplicate 與
  session 邊界；不能因本次短時推送成功就通過完整 G2。沒有帳戶、解鎖、下單、push 或部署。

Callback 接法核對了 [官方文件](https://openapi.futunn.com/futu-api-doc/en/quote/update-stock-quote.html)
及本機 pinned SDK 10.12.7208 原碼；新版本仍需重驗。
