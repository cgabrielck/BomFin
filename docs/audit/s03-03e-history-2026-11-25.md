## 交付與界線

- `history_smoke` 固定 US.AAPL、前一紐約曆日、未調整 K_1M。
  RTH／ETH 各一個最多兩筆的原始頁，沒有日期擴張、重試或 page-token 追頁。
  前一曆日可能不是交易日，empty 保持明示；沒有下載完整回測資料。
- 歷史配額前後只保存 used／remaining，`get_detail=False`。未知／耗盡時停止；
  七天每標的一個歷史名額不是即時訂閱名額，不承諾 close 後歸零。
- 僅行情 context，無訂閱、帳戶查詢、交易或 OpenD 重啟。保留 SDK 隔離程序，
  raw stdout／stderr、股票名稱、quota detail、page token 及原始例外不進結果。
- RTH／ETH 分別回 available、empty、failed、invalid_data 或 not_attempted；
  預算不足時保留已讀樣本。逐項列出 PRE／RTH／POST 的 sampled／not_sampled，
  只按來源標籤鐘面時間分類，並非完整日曆或 bar 起訖／finalized 定義。
- `get_market_state` 是當前市場 metadata；`live_rights=unverified` 始終保留。
  歷史樣本不能證明即時盤前／盤後權益、推送延遲或可交易性。

## SDK 缺口與修正

- 固定 SDK 10.12.7208 的高階歷史方法會為不足兩筆的頁自行追 token；
  其解碼器亦在列迴圈外重用字典，缺失 OHLC 可能承接前列。
  這是對安裝原始碼的檢查結果，不宣稱本次實際價格曾遭污染。
- `history_wire.py` 只用該版本行情 packer 與 `_query_sync` 發一次請求，
  每筆 proto 獨立檢查 HasField、security、日期、數量與 OHLC；blank／缺欄
  不補值、不填頁。成功但格式錯誤與 transport failure 分類分開。
- 這是版本鎖定的私有 transport hook，worker 有版本 gate；升級 SDK 前
  必須重做 protocol／parser／實際 smoke，不能假定跨版本相容。
- CLI 預設 110 秒、允許 70–120 秒。讀歷史前保留 60 秒；metadata／最後
  配額查詢前保留 28 秒，依固定 SDK 最多 20 秒等待及 3 秒連線等待留緩衝。
  不足便回 skipped／budget_exhausted 後 close，parent 核對跳過階段的一致性。
- 初始化與 import 異常亦會嘗試 close。任意 SDK 卡住、主機休眠或強殺
  仍可能造成 timeout；此時不會冒稱完成清理或保有全部結果。

## 非預期失敗的處理

- 一次補 UTC 檢查漏了括號，造成模組 SyntaxError；不是預期 TDD RED。
  [失敗](artifacts/s03-03e/green-3.log) 與 [修正後](artifacts/s03-03e/green-3-fixed.log)。

  查明原 SDK 的日期正規化後，恢復 00:00:00–23:59:59，新增先失敗的日期
  測試並重跑成功。[empty 證據](artifacts/s03-03e/live-history-single-page-empty.json)。
