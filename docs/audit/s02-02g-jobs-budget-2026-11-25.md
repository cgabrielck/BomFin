## Engineering rulings and costs

- Lease token is hidden in model repr but remains in internal wire serialization. This is not a complete redaction guarantee: validation errors and dumped documents must not be logged/exposed unfiltered by later services. Token generation, rotation and fencing are not implemented.
- Acquisition timestamp is explicit so lease interval consistency can be checked without current-clock coupling. Runtime lease expiry and exclusive ownership still require transactional server checks.
- Unknown estimated spend cannot be represented as a valid amount=None reservation. Future service must defer/reject or obtain approved trial authority; this unit installs no spending policy/default amount.
- Preserve actual overrun as an accounting fact instead of rejecting it; later ledger must reconcile, report and enforce caps without silently increasing approved budget.
- Status records a snapshot, not a verified transition. No release after worker death/timeout/lease expiry is inferred; currency conversion, concurrent reservations, idempotency, monthly caps and ambiguous provider charges remain Task 6 responsibilities.
- No scheduler, heartbeat, cancellation, actual budget debit/reservation, model call, migrations, API, trading or deployment implemented.
- Next: bounded ModelRequest/ModelResult contracts. Other remaining support groups, aggregate schema, SQLite and Task 3 authorization remain incomplete.
