## Engineering rulings / limits

- Scope strings/actor and budget UUIDs are metadata: actual authorization/reservation and request/snapshot ownership checks belong to services.
- Calendar/event interpretation and source authenticity/hash verification are external duties; hash shape is validated here. Source URL credentials are rejected.
- Event window currently stores a nullable duration; it does not implement signed pre/post event-study windows or resolve exchange calendars. These may be extended when an actual consumer requires them.
