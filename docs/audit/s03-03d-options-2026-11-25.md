## 界線及下一步

- 可讀到舊價不等於即時權益；未驗證當前開市變動、推送延遲、Greeks、
  歷史期權或 PRE／POST。固定測試窗口也不是正式 catalog／訂閱 allocator。
- 75 秒是訂閱前的預算關卡，並非保證任意 SDK 卡住、主機休眠或程序被殺後
  仍能完成清理。parent timeout 後必須另查 metadata／quota，不能宣稱已釋放。
- 本單位不生產正式 QuoteSnapshot／Instrument catalog，也不授予交易能力。
- 下一單位：S03/03e 歷史資料／session 能力的有界診斷，先核對配額與
  可驗時段；完整 S03 仍有 catalog、allocator、push／cache／replay 等工作。

## 查閱的官方依據

- [到期日](https://openapi.futunn.com/futu-api-doc/en/quote/get-option-expiration-date.html)、
  [靜態鏈](https://openapi.futunn.com/futu-api-doc/en/quote/get-option-chain.html)：
  鏈的日期範圍與 lot_size 等身份資料；SDK OptionDataFilter 未提供 strike 篩選。
- [quote](https://openapi.futunn.com/futu-api-doc/en/quote/get-stock-quote.html)：
  使用 code 訂閱後取得報價；保留來源日期、時間及股票期權合約規模。
- [訂閱限制](https://openapi.futunn.com/futu-api-doc/en/qa/quote.html)：最短持有期。
  兩個本連線配額欄位另核對固定版 SDK query_subscription 原始碼。
- [Python monotonic](https://docs.python.org/3.12/library/time.html#time.monotonic)：
  Python 3.12 的 system-wide monotonic 可在本機父子程序比較剩餘時間。
